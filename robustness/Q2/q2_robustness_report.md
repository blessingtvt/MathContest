# Q2 稳健性报告（robustness-checker，round3）

> 主模型 M2 = 逐日滚动 LP + 附件2历史自预报（7天加权）+ 80分位风险修正。
> 本报告只针对 G2 识别的 load-bearing 风险点做定向检验，不做无关测试堆砌。
> 数据来源：`data_clean/cleaned_data.pkl`；种子 SEED=2026；报告期 2025-02-01 ~ 12-31。

## 检验结论一览

| ID | 检验点 | 扰动 | 结果 | 状态 |
|---|---|---|---|---|
| R1 | 风险分位 q 最优性 | q∈{0,30,50,70,80,90,95,99} | argmin=80，与报童临界比一致 | **PASS** |
| R2 | 预报窗口/加权 | 3/5/7/14 天均匀 vs 7天加权 | 3天 +14%；5/7/14天 ±2% | **CONDITIONAL** |
| R3 | 效率口径 HD2 | η=0.9 单向 vs √0.9 往返 | 总费 −3.0%，价值方向不变 | **PASS** |
| R4 | 电价线性 | p×{0.9,0.95,1.0,1.05,1.1} | 精确线性 | **PASS** |
| R5 | 日末循环约束 | S_144=S_0 vs 自由终态 | +0.13% | **PASS** |

## R1 风险分位敏感性（核心风险点）

报童临界比 $(α_{em}−1)/(α_{em}−1+1) = 4/5 = 0.8$ 预测 80 分位最优，实测精确吻合：

| 分位 q | 总费用(元) | 紧急费占比 |
|---|---|---|
| 0（无修正） | 57,567,252.07 | 92.76% |
| 30 | 26,403,078.64 | 56.24% |
| 50 | 20,105,495.72 | 32.09% |
| 70 | 18,223,007.92 | 18.10% |
| **80** | **17,741,097.14** | **11.28%** |
| 90 | 17,793,134.79 | 4.75% |
| 95 | 18,228,658.05 | 2.31% |
| 99 | 19,503,771.29 | 0.69% |

**结论**：总费用在 q=80 处取最小，且 q=0（无风险修正）费用暴涨 3.2 倍，证明风险修正机制是模型不可省略的核心，而非参数微调。

## R2 预报窗口敏感性（CONDITIONAL）

| 预报方案 | 总费用(元) @ q=80 |
|---|---|
| 3 天均匀 | 20,226,034.85 |
| 5 天均匀 | 17,979,113.74 |
| 7 天均匀 | 16,875,313.78 |
| 7 天加权（基准） | 17,741,097.14 |
| 14 天均匀 | 17,388,171.48 |

**结论**：预报窗口是模型唯一的可调超参数。3 天窗口明显劣化（+14%），但 5/7/14 天窗口的总费用波动在 ±2% 内；7 天加权并非唯一最优（14 天均匀略优 −2%）。这不影响"储能 + 风险修正显著降费"的主结论，但论文应如实标注绝对费用对预报调优存在 ±2% 量级敏感。

## R3 效率口径（HD2）

| 口径 | 总费用(元) |
|---|---|
| 单向 η=0.9（往返 0.81） | 17,741,097.14 |
| 往返 0.9（单向 √0.9≈0.9487） | 17,203,867.05 |

效率口径改变总费用约 −3.0%；无储能基线不受 η 影响，故储能价值在两种口径下均显著为正（>400 万元），结论稳健。HD2 建议在论文正文明确"单向效率"口径。

## R4 电价线性扰动

费用随电价**精确线性**（×0.9→15,966,987.43；×1.1→19,515,206.85，与基准精确成比例），LP 无放大/振荡，无敏感性风险。

## R5 日末循环约束

日末循环 S_144=S_0=6000 相比自由终态仅使总费用增加 22,728.82 元（+0.13%），换取"每日可独立重复运行"的物理合理性，取舍成立。

## 总体判定

**CONDITIONAL**（非 FAIL，非需回退）：四项 PASS + 一项 CONDITIONAL。模型结构与风险修正机制稳健；唯一 CONDITIONAL 项为预报超参数的 ±2% 调优空间，属可接受的局限性，不触发 fallback（F2 鲁棒/随机规划）。
