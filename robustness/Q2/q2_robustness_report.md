# Q2 稳健性报告（robustness-checker，round4）

> 主模型 M2 = 逐日滚动 LP + 附件2历史自预报（7天加权）+ 80分位**按星期分桶**风险修正 e80[dow]。
> 本报告只针对 G2 识别的 load-bearing 风险点做定向检验，不做无关测试堆砌。
> 数据来源：`data_clean/cleaned_data.pkl`；种子 SEED=2026；报告期 2025-02-01 ~ 12-31。
> 数值与 `robustness/Q2/q2_robustness_summary.json`、`results/Q2/reports/frozen_numbers.json` 一致。

|---|---|---|---|---|

## R1 风险分位敏感性（核心风险点）

报童临界比 $(α_{em}−1)/(α_{em}−1+1) = 4/5 = 0.8$ 预测 80 分位最优；按星期分桶后经验 argmin 移至 q=90（储能降低"多购浪费"代价使最优分位略右移），q=80 仅高 0.67%、目标在 70–95 平坦：

| 分位 q | 总费用(元) | 紧急费占比 |
|---|---|---|
| 0（无修正） | 25,093,998.32 | 60.16% |
| 30 | 17,575,991.73 | 34.23% |
| 50 | 15,913,613.91 | 24.04% |
| 70 | 14,870,741.86 | 14.93% |
| **80** | **14,559,104.58** | **10.65%** |
| 90 | 14,461,289.17 | 6.45% |
| 95 | 14,624,319.15 | 4.36% |
| 99 | 15,197,625.85 | 2.75% |

**结论**：总费用在 q=90 处取最小 14,461,289.17 元，q=80 为 14,559,104.58 元（仅高 0.67%）；而 q=0（无风险修正）费用暴涨至 25,093,998.32 元（约 1.7 倍），证明风险修正机制是模型不可省略的核心，而非参数微调。

## R2 预报窗口敏感性（CONDITIONAL）

| 预报方案 | 总费用(元) @ q=80 |
|---|---|
| 3 天均匀 | 14,598,674.81 |
| 5 天均匀 | 14,589,673.55 |
| 7 天均匀 | 14,660,223.93 |
| 7 天加权（基准） | 14,559,104.58 |
| 14 天均匀 | 15,251,373.61 |

**结论**：预报窗口是模型唯一的可调超参数。7 天加权基准恰为各窗口最低；3/5/7 天均匀窗口偏差仅约 +0.7% 以内，14 天均匀窗口劣化至 +4.76%。这不影响"储能 + 风险修正显著降费"的主结论，但论文应如实标注绝对费用对预报窗口存在个位数百分比的敏感（CONDITIONAL）。

## R3 效率口径（HD2）

| 口径 | 总费用(元) |
|---|---|
| 单向 η=0.9（往返 0.81） | 14,559,104.58 |
| 往返 0.9（单向 √0.9≈0.9487） | 14,092,449.45 |

效率口径改变总费用约 −3.2%；无储能基线不受 η 影响，故储能价值在两种口径下均显著为正（基准口径 3,613,022.84 元，往返口径下更高），结论稳健。HD2 建议在论文正文明确"单向效率"口径。

## R4 电价线性扰动

费用随电价**精确线性**（×0.9→13,103,273.13；×1.1→16,015,015.04，与基准精确成比例），LP 无放大/振荡，无敏感性风险。

## R5 日末循环约束

日末循环 S_144=S_0=6000 相比自由终态仅使总费用增加 8,654.26 元（+0.06%），换取"每日可独立重复运行"的物理合理性，取舍成立。

## 总体判定

**CONDITIONAL**（非 FAIL，非需回退）：四项 PASS + 一项 CONDITIONAL。模型结构与风险修正机制稳健；唯一 CONDITIONAL 项为预报窗口的调优空间，属可接受的局限性，不触发 fallback（F2 鲁棒/随机规划）。
