## 六、问题三：基于滚动时域 MPC 的微网动态调度优化模型

### 6.1 问题分析

问题三将微网购电决策置于预报信息随时间滚动更新的真实场景中：光伏预报由附件 3 在每天 0:00、6:00、12:00、18:00 分四次发布未来 24 小时的预报，实际结算却始终以附件 2 的实测光伏为准；**负载侧数据取自附件 2 的小区实际负载，题设未提供负载预测，故将负载视为确定已知**▲1。因此决策者必须先定计划、再作调整：0:00 依据当日预报确定覆盖全天 144 个区间的计划购电量 $x_{d,\cdot}$，此后三个时刻只能依据各自最新预报对剩余时段追加调整。问题的本质归结为：在信息逐步揭示、预报又必然有偏的条件下，如何让购电策略随信息更新而动态修正，并使报告期总费用最小。

其难度集中在三处：分段计价使费用非光滑、难以直接线性求解；储能跨日耦合，若不加日末约束会被倒空而丧失套利价值；预报偏差具系统性且按发布时刻变化，高估光伏将直接导致缺口以最贵电价填补。据此，求解思路沿三条主线展开：时间上采用滚动时域思想，把全年决策拆解为逐日多次优化，每个信息发布时刻都从当前储能状态出发、以最新预报重规划剩余时段，使策略随信息闭环修正；数学上引入"计划内 $u$＋违约 $v$＋溢价 $w$"辅助变量还原分段计费，把原问题转化为可高效求解的线性规划▲5；预报上按发布时刻分别刻画偏差规律、以历史统计分位数构造偏保守的规划预测，将高估所引发的缺电与高价购电风险，转化为计划略偏保守所导致的少量弃光代价。

### 6.2 模型建立

#### 6.2.1 滚动时域调度机制

本文采用滚动时域模型预测控制（Model Predictive Control，MPC）进行微网动态调度。设一天内预测发布时刻集合为
$$S=\{0,6,12,18\}\tag{25}$$
其中，0:00 时刻根据全天光伏预报（经风险修正）制定覆盖全天 144 个区间的初始计划购电量 $x_{d,t}$；6:00、12:00、18:00 时刻分别依据最新预报对剩余区间重新优化，得到调整购电量 $y_{d,t}$▲2。滚动过程中，已执行区间的购电量冻结为计划值（即该区间 $y_{d,t}=x_{d,t}$），未执行区间以待更新的 $y_{d,t}$ 执行。计划随发布时刻滚动更新为 $x_{d,\cdot}^{(0)}\to x_{d,\cdot}^{(6)}\to x_{d,\cdot}^{(12)}\to x_{d,\cdot}^{(18)}$，上标表示发布时刻▲3。为保证储能系统连续运行，设置日末闭合约束
$$E_{d,144}=E_{d,0}=6000\tag{26}$$

#### 6.2.2 光伏预测风险修正模型

由于光伏预报存在误差，实际出力可能低于预报值，导致计划购电不足并触发高价紧急购电。定义第 $d$ 天第 $s$ 次发布时刻、作用于执行区间 $t$ 的光伏高估误差▲4：
$$e_{d,s,t}=\hat G_{d,s,t}-G_{d,t}\tag{27}$$
其中 $\hat G_{d,s,t}$ 为第 $s$ 次发布的整点预报 $\hat G_{d,s,h}$ 阶梯映射到区间 $t$（$t$ 所在小时 $h=\lfloor t/6\rfloor$）的取值，$G_{d,t}$ 为实际光伏功率。为避免使用未来信息（信息泄漏），风险修正仅利用历史日期（$j<d$）同一发布时刻、同类提前时长的误差统计，取 80% 分位数作为修正量：
$$\delta_{d,s,t}=P_{80}\!\big(e_{j,s,t}:j<d,\ \text{同 }s\text{ 同提前时长}\big)\tag{28}$$
得到风险修正后的安全光伏预报：
$$\hat G^{\rm safe}_{d,s,t}=\max\!\big(0,\ \hat G_{d,s,t}-\delta_{d,s,t}\big)\tag{29}$$
通过下调光伏预报预留安全裕度，把"预报高估 → 购电不足 → 紧急购电"的风险转化为少量弃光代价。

#### 6.2.3 分段购电成本模型

考虑计划购电与调整购电的分段计费，定义：$x_{d,t}$ 为 0:00 制定的计划购电量（**仅作计费基准**），$y_{d,t}$ 为滚动调整后的实际执行购电量，$z_{d,t}$ 为紧急购电量▲2。第 $t$ 区间的购电成本表示为：
$$C_{d,t}=p_t\Big[\min(x_{d,t},y_{d,t})+0.5\max(x_{d,t}-y_{d,t},0)+1.5\max(y_{d,t}-x_{d,t},0)\Big]\tag{30}$$
三项分别为：计划内执行部分按原价 $p_t$ 结算；计划未执行部分按 $0.5p_t$ 计违约费；超计划部分按 $1.5p_t$ 计溢价费。该分段函数非光滑，为便于线性规划求解，引入辅助变量 $u_{d,t},v_{d,t},w_{d,t}$▲5：
$$u_{d,t}\le x_{d,t},\ u_{d,t}\le y_{d,t},\ u_{d,t}\ge 0;\qquad v_{d,t}\ge x_{d,t}-y_{d,t},\ v_{d,t}\ge 0;\qquad w_{d,t}\ge y_{d,t}-x_{d,t},\ w_{d,t}\ge 0$$
由于目标中三者系数均为正，最优解自动满足 $u_{d,t}=\min(x_{d,t},y_{d,t})$、$v_{d,t}=\max(x_{d,t}-y_{d,t},0)$、$w_{d,t}=\max(y_{d,t}-x_{d,t},0)$，且满足执行量守恒
$$u_{d,t}+w_{d,t}=y_{d,t}$$
若执行后仍存在供需缺口，则以 5 倍电价紧急购电：
$$C^{\rm em}_d=5\sum_{t=1}^{T}p_t\,z_{d,t}\tag{31}$$

#### 6.2.4 优化模型

以报告期（全年逐日累积）购电成本最小为目标，每日 $d$ 在发布时刻 $s$ 求解窗口优化问题▲8：
$$\min\ C_d=\sum_{t}p_t\big(u_{d,t}+0.5\,v_{d,t}+1.5\,w_{d,t}\big)+5\sum_{t}p_t\,z_{d,t}\tag{32}$$
约束条件如下。

（1）功率平衡约束（$y$ 为最终执行购电量，计划 $x$ 不重复计入）▲6：
$$y_{d,t}+z_{d,t}+\hat G^{\rm safe}_{d,s,t}\,\Delta t+q_{d,t}=L_{d,t}\,\Delta t+c_{d,t}\tag{33}$$

（2）储能状态转移约束：
$$E_{d,t}=E_{d,t-1}+\eta_c\,c_{d,t}-\frac{q_{d,t}}{\eta_d}\tag{34}$$

（3）储能容量约束：
$$E_{\min}\le E_{d,t}\le E_{\max}\tag{35}$$

（4）充放电功率约束▲7：
$$0\le c_{d,t}\le P^{\rm c}_{\max}\Delta t,\qquad 0\le q_{d,t}\le P^{\rm d}_{\max}\Delta t\tag{36}$$

（5）购电量非负约束：
$$y_{d,t},\ z_{d,t}\ge 0\tag{37}$$

（6）日末储能闭合约束：
$$E_{d,144}=E_{d,0}=6000\tag{38}$$

其中 $P^{\rm c}_{\max}=P^{\rm d}_{\max}=5000$ kW，$E_{\min}=1200$、$E_{\max}=10800$ kWh，$\Delta t=1/6$ h。上述为"单日、单发布时刻"的窗口优化，全年总费用 $C_3=\sum_d C_d$；每次重规划仅覆盖剩余区间 $t\in[6s+1,144]$，已执行区间冻结。

**需特别区分两个口径**▲9：优化阶段以安全预报 $\hat G^{\rm safe}_{d,s,t}$ 作为光伏供给输入（偏保守），$z_{d,t}$ 仅作为安全阀变量；结算阶段则用真实光伏 $G_{d,t}$ 校验实际供需，仅当 $y_{d,t}+G_{d,t}\Delta t+q_{d,t}<L_{d,t}\Delta t$ 时按缺口计 $z_{d,t}$（5 倍价）。两者分离，保证优化不含未来信息、结算反映真实成本。

### 6.3 模型求解

本文采用滚动时域优化方法求解，求解过程可概括为"**风险修正 → 0:00 计划 → 逐时刻重规划 → 日末闭合**"四步，形式化描述见算法 2▲10。

**算法 2　滚动时域 MPC（问题三）**

```
输入：附件3 整点光伏预报 Ĝ_{d,s,h}（s∈{0,6,12,18}, h=1..24），实际光伏 G_{d,t}，
      负载 L_{d,t}（题设视为已知），电价 p_t，
      储能参数 C=12000, E_min=1200, E_max=10800, P^c_max=P^d_max=5000, ηc=ηd=0.9, E_0=6000，
      计费系数 β=0.5, γ=1.5, α=5
输出：result3.xlsx —— 计划 x_{d,t}、调整 y_{d,t}、紧急 z_{d,t}；全年总费用 C3

 1  C3 ← 0
 2  for d = 1, …, D:                                   // 逐日滚动
 3      // ① 风险修正：每个发布时刻 s，用历史 j<d 的误差分位构造安全预报（因果，不用未来）
 4      for s ∈ {0, 6, 12, 18}:
 5          δ_{d,s,t} ← P_80({ Ĝ_{j,s,t} − G_{j,t} : j<d, 同 s 同提前时长 })
 6          Ĝ^safe_{d,s,t} ← max(0, Ĝ_{d,s,t} − δ_{d,s,t})
 7      // ② 0:00 制定覆盖全天的计划 x_{d,·}（用 Ĝ^safe_{d,0,t}）
 8      x_{d,·} ← SolveLP( 区间 t∈[1,144], 初值 E_{d,0}=6000,
 9                          目标  min Σ_t p_t x_{d,t},
10                          约束  x_{d,t} + Ĝ^safe_{d,0,t}Δt + q_{d,t} = L_{d,t}Δt + c_{d,t}
11                               E_{d,t} = E_{d,t-1} + ηc·c_{d,t} − q_{d,t}/ηd,  E_min ≤ E ≤ E_max
12                               0≤c≤P^c_max·Δt, 0≤q≤P^d_max·Δt, x_{d,t} ≥ 0
13                               E_{d,144} = E_{d,0} = 6000 )
14      // ③ 滚动调整：6:00 / 12:00 / 18:00 依次用新预报重规划剩余区间
15      for s ∈ {6, 12, 18}:
16          i ← 6s + 1                                  // 该时刻对应首个待决策区间：37 / 73 / 109
17          y_{d,[i,144]} ← SolveLP( 区间 t∈[i,144], 初值 E_{d,i-1}（由已执行段推得）,
18                      目标  min Σ_{t=i}^{144} p_t(u_t + 0.5 v_t + 1.5 w_t) + 5 Σ_{t=i}^{144} p_t z_{d,t},
19                      约束  y_{d,t} + z_{d,t} + Ĝ^safe_{d,s,t}Δt + q_{d,t} = L_{d,t}Δt + c_{d,t}
20                           E_{d,t} = E_{d,t-1} + ηc·c_{d,t} − q_{d,t}/ηd,  E_min ≤ E ≤ E_max
21                           0≤c≤P^c_max·Δt, 0≤q≤P^d_max·Δt, y,z ≥ 0
22                           分段计费线性化：u_t≤x_{d,t}, u_t≤y_{d,t}, u_t≥0;
23                              v_t≥x_{d,t}−y_{d,t}, v_t≥0;  w_t≥y_{d,t}−x_{d,t}, w_t≥0
24                           E_{d,144} = E_{d,0} = 6000 )
25          执行区间 [i, i+36)：令 y_{d,t} ← 上述 LP 解；储能状态前推至 E_{d,i+35}
26      // ④ 冻结未调整区间：t∈[1,36] 维持 y_{d,t} = x_{d,t}（0:00–6:00 直接执行计划）
27      // ⑤ 结算：用最终 (x,y,z) 计当日费用，逐日累加
28      C3 ← C3 + Σ_{t=1}^{144} p_t[ min(x_{d,t},y_{d,t}) + 0.5 max(x_{d,t}−y_{d,t},0)
29                                   + 1.5 max(y_{d,t}−x_{d,t},0) ] + 5 Σ_t p_t z_{d,t}
30  end for
31  return C3
```

对算法 2 的三处关键设计说明如下：
1. 第 3–6 行的风险修正只用 $j<d$ 历史误差，避免信息泄漏；
2. 第 15–25 行每次重规划只优化剩余区间 $[i,144]$ 且只执行 $[i,i+36)$，实现"决策随信息滚动"；
3. 每次 LP 均施加 $E_{d,144}=E_{d,0}$，防止储能被倒空、保证跨日套利价值。

模型采用 Python 中的 `scipy.optimize.linprog` 求解，调用 HiGHS 求解器获得各时间窗口的最优解。

#### 6.4.6 随机规划扩展对比分析

为进一步分析预测不确定性对调度策略的影响，在主模型基础上引入随机规划（Stochastic Programming，SP）作为扩展对照方法，通过构造多个光伏预测误差场景描述不确定性。结果见表 6.3。

**表 6.3　随机规划扩展模型对比结果**

| 方法 | 成本（元） | 说明 |
|---|---|---|
| SP 样本外实际结算 | 13,791,763.20 | 真实光伏滚动结算 |
| SP 样本内期望成本（RP） | 13,833,708.88 | 随机规划期望成本 |
| WS 完全预见 | 12,245,046.92 | 理想信息下界 |
| EVPI | 1,588,661.96 | 完全信息价值 |

其中完全预见（WS）以真实光伏代入且紧急购电 $z=0$，即完全预知光伏时计划即最优、无调整惩罚，故构成任何预报方案的理论下界 1224.50 万元▲14。定义完全信息价值 $\mathrm{EVPI}=$ 随机规划期望成本 $-$ 完全预见成本 $=1383.37-1224.50=158.87$ 万元，度量"若完全预知光伏"可再节省的上限。SP 期望成本（1383.37 万元）与样本外结算（1379.18 万元）均略优于 MPC 主模型的 1405.00 万元，但考虑随机规划需构造多场景、计算量成倍增加而收益仅约 2%，本文最终采用滚动时域 MPC 作为主要优化策略。
