## 一、总体结论

论文的**骨架方向是对的**（Q1 静态 LP → Q2 逐日滚动+风险修正 → Q3 滚动 MPC+分段计费 → Q4 波动电价复用），四问递进关系在思路上成立。但存在 **5 处致命硬伤**，集中表现为三类：

1. **模型断裂**：Q2/Q3 都建了"预测/风险修正子模型"，但优化主模型没把修正值接进约束（建而不用）；
2. **符号/公式错位**：Q3 能量平衡把计划购电 `x` 与调整购电 `y` 重复相加；Q3 求解步骤整段抄成 Q4 的电价内容；Q1 把"预测光伏"写成"实际光伏"；
3. **数值不自洽**：Q3 消融表与冻结数据冲突；符号表决策变量漏 `d` 下标。

按"逻辑自洽 + 模型完整度"这个你最看重的维度，**必改项是 F1–F6**，改完逻辑链就通了；其余是润色与精简。

## 二、致命问题（必须改）

### F1　Q3 求解步骤整段错位（6.3 节）
正文 6.3 标题是"问题三…MPC"，但 7 个求解步骤通篇讲"读取附件 4 动态电价""电价更新时间 si"“与固定电价策略比较"。**这是 Q4 的求解流程，被误抄进了 Q3。**

- 现状：Step1"读取附件 4 提供的动态电价数据"；Step3"当到达电价更新时间 si 时…"；Step7"分析动态电价条件下模型的经济性"。
- 应改为：Q3 是**光伏预报在 0/6/12/18 四点滚动发布**，求解步骤应为"取当日四次预报→逐 s 做风险修正→重规划剩余区间→执行到下一发布时刻→日末闭合"。

### F2　Q3 能量平衡双重计数（公式 (34)）
```
xt + yt + zt + Gt∆t + qt = Lt∆t + ct        (34)   ← 错
```
`xt`（0:00 计划）与 `yt`（调整后实际购电）是**同一电量的两个口径**，不能相加。物理上执行的是 `yt`。正确写法（并显式用安全预报）：
```
yt + zt + Ĝ^{safe}_{s,t}·∆t + qt = Lt·∆t + ct
```
`xt` 只作为**计费基准**进入费用项 `min(xt,yt)`，不进入能量平衡。这一条与 `symbol_table.md` §8 的约定一致（"Q3 中 x 为最终购电 = y"）。

### F3　预测/修正子模型"建而不用"（Q2、Q3 同病）
- **Q2**：5.2.1–5.2.2 建立了 `N̂_{d,t}` 和 `N^{safe}_{d,t} = N̂ + δ`，但 5.2.3 的优化模型 (14)–(15) 目标与能量平衡用的仍是 `Gt、Lt`（实际值），**`N^{safe}` 与 `δ` 完全没进入约束**。日前优化应当用 `N^{safe}`（或等价的 `L̂ − Ĝ^{safe}`）作为输入，而不是事后已知的实际值。
- **Q3**：6.2.2 建立了 `Ĝ^{safe}_{s,t}`，但 6.2.4 的 (34) 用的是 `Gt`（实际光伏）。**修正值同样没接入**，且用 `Gt` 是"决策时已知未来光伏"的信息泄漏（look-ahead bias）。

这是全文最大的逻辑硬伤：**前面讲预报与风险，后面优化却跳过预报直接用真值**。修正后两问的"预测→修正→优化"三段才能首尾相接。

### F4　Q3 消融数值与冻结数据冲突（表 6.1）
论文表 6.1 与 `frozen_numbers.json` / `robustness_report.json` 对不上：

| 方案 | 论文现值 | 冻结真值 |
|---|---|---|
| 仅 0:00 | 16,407,000 | **17,291,136.58** |
| +6:00 | 15,208,000 | **14,511,749.80** |
| +12:00 | 15,153,000 | **14,050,000.56** |
| +18:00 | 14,049,999.28 | 14,049,999.28（一致）|

只有最后一个值对上了，前三个是另一版（或编的）。且论文把 +18:00 拆成"计划 12,208,135.40 + 调整 1,277,803.18"，但 +6、+12 两行的"调整费用"却写 0——**逻辑矛盾**（只要 6:00 做了调整就必然有违约/溢价费）。**表 6.1 必须整体替换为冻结值**，并给出"计划费/调整费/紧急费"三栏的一致口径。

### F5　Q1 光伏符号错用（Gt vs Ĝt）
附件 1 给的是**光伏预测**，Q1 能量平衡 (2) 却写 `xt + Gt∆t + qt = ...`。按 `symbol_table.md`，Q1 单日预测应为 `Ĝ_t`（实际光伏 `G_{d,t}` 属附件 2、Q2–Q4）。Q1 应统一用 `Ĝ_t`，并加一条假设"Q1 将预测视为确定"。

### F6　Q3 内部符号不统一（s/k、y_{s,t}/y_t）
- 符号表用 `Ĝ_{k,t}、e_{k,t}、δ_k、Ĝ^{safe}_{k,t}`（下标 k），正文 6.2 用 `Ĝ_{s,t}、e_{s,t}、δ_{s,t}`（下标 s）。**k 与 s 混用**。
- 6.2.1 用 `y_{s,t} = x^{(s)}_t`，6.2.3/6.2.4 又退化成 `y_t`。同一篇论文同一变量三种写法。

## 五、模型递进路线（建议写入 1.3，配 `fig_0_framework.png`）

四问是一条**连续的升级链**，每级都在修补上一级的局限：

| 问 | 输入升级 | 模型升级 | 解决的局限 |
|---|---|---|---|
| Q1 | 附件1 单日预测 Ĝ | 静态 LP | 基准，无预测 |
| Q2 | 附件2 全年实际（历史自预报 N̂）| 逐日滚动 + 报童修正(q=0.8) | Q1 只有单日、无法应对全年预测误差 |
| Q3 | 附件3 四点滚动预报 Ĝ_{s,h} | 日内滚动 MPC + 分段计费 | Q2 只在 0:00 决策一次，无法用后续预报纠偏 |
| Q4 | 附件4 波动电价 p_{d,t} | 复用 Q2/Q3 滚动框架 | 前三问电价恒定 |

一句话主线：**"预报越来越新、决策越来越勤、计费越来越细"**，模型也随之从静态 LP 逐步演进为滚动 MPC，全程共享同一套能量平衡/储能动态/日闭合内核（即 `fig_0_framework.png` 的"建模内核"层）。

## 六、伪代码（Q2、Q3，最能体现建模的两问）

### 算法 1　逐日滚动日前优化（问题二）

```
输入：历史净负荷 {N_{j,t}}，星期类型 s(d)，电价 p_t，储能参数 (C,Emin,Emax,Pcmax,Pdmax,ηc,ηd,E0)，
      权重 w=[0.30,0.20,0.15,0.12,0.10,0.08,0.05]，报童分位 q=0.8
输出：result2.xlsx —— 全年 {x_{d,t}}, {z_{d,t}}, 储能轨迹 {E_{d,t}}, 总费用 C2

for d = 1, 2, …, D:                       # D 为结算天数
    # ① 净负荷自预报（仅用 <d 的历史，星期分桶）
    N̂_{d,t} = Σ_{k=1..7} w_k · N_{d-k,t}
    # ② 风险修正：同星期历史误差的 80% 分位（报童临界比 q*=0.8）
    δ_d = Q_{0.8}( { N_{j,t} − N̂_{j,t} : 星期(j)=星期(d), j<d } )
    N^{safe}_{d,t} = N̂_{d,t} + δ_d
    # ③ 日前计划 LP（决策变量 x_{d,t}, c_{d,t}, q_{d,t}, E_{d,t}）
    min  Σ_t p_t · x_{d,t}
    s.t. x_{d,t} + N^{safe}_{d,t}·Δt + q_{d,t} = c_{d,t}          # 能量平衡（用安全净负荷）
         E_{d,t} = E_{d,t-1} + ηc·c_{d,t} − q_{d,t}/ηd             # 储能动态
         1200 ≤ E_{d,t} ≤ 10800,  0≤c_{d,t}≤5000·Δt,  0≤q_{d,t}≤5000·Δt
         E_{d,0} = E_{d,144} = 6000                                # 日末闭合
    得 {x_{d,t}}, {c_{d,t}}, {q_{d,t}}, {E_{d,t}}
    # ④ 执行 + 用真实 L_{d,t}, G_{d,t} 结算，缺口触发紧急购电
    for t = 1..T:
        if x_{d,t} + G_{d,t}·Δt + q_{d,t} < L_{d,t}·Δt:
            z_{d,t} = L_{d,t}·Δt − ( x_{d,t} + G_{d,t}·Δt + q_{d,t} )
        else: z_{d,t} = 0
    C2 += Σ_t p_t · ( x_{d,t} + 5·z_{d,t} )
return C2
```

### 算法 2　滚动时域 MPC（问题三）

```
输入：附件3 预报 Ĝ_{d,s,h}（s∈{0,6,12,18}），实际 G_{d,t}，电价 p_t，
      计费系数 β=0.5, γ=1.5, α=5
输出：result3.xlsx —— 计划 x、调整 y、紧急 z，总费用 C3

for d = 1, 2, …, D:
    x_{d,·} = 求解0:00计划LP(用 Ĝ^{safe}_{d,0,t}，全天144区间)      # 初始计划，覆盖全天
    for s in {0, 6, 12, 18}:
        # ① 风险修正：同 s 时刻、同类区间历史高估误差的 80% 分位（因果滚动，仅用 j<d）
        δ_{d,s,t} = P_{80}( { Ĝ_{j,s,t} − G_{j,t} : j<d, 同 s } )
        Ĝ^{safe}_{d,s,t} = max(0, Ĝ_{d,s,t} − δ_{d,s,t})
        # ② 从当前储能状态 E_{d,6s} 出发，重规划剩余区间 t∈[6s,144]
        #    分段计费线性化：u_t=min(x_t,y_t) 计划内, v_t=max(x_t−y_t,0) 违约,
        #                   w_t=max(y_t−x_t,0) 溢价（u≤x,u≤y; v≥x−y,v≥0; w≥y−x,w≥0）
        min  Σ_t p_t·( u_t + 0.5·v_t + 1.5·w_t ) + 5·Σ_t p_t·z_t
        s.t. y_t + z_t + Ĝ^{safe}_{d,s,t}·Δt + q_t = L_t·Δt + c_t     # 能量平衡（y 为最终购电）
             E_t = E_{t-1} + ηc·c_t − q_t/ηd,  1200≤E≤10800
             0≤c_t≤5000Δt, 0≤q_t≤5000Δt, y_t,z_t≥0
             E_{d,144} = E_{d,0} = 6000
        执行区间 [6s, 6s+6) 的控制量，并令已执行区间 y_t = x_t
    C3 += Σ_t p_t·[ min(x_t,y_t)+0.5max(x_t−y_t,0)+1.5max(y_t−x_t,0) ] + 5·Σ_t p_t·z_t
return C3
```

> 说明：Q2 伪代码体现"**预测—修正—优化—结算**"闭环；Q3 伪代码体现"**滚动时域 + 分段计费线性化 + 只执行到下一更新时刻**"的 MPC 思想。两段放在对应节的"模型求解"开头，能显著补强"模型完整度"。

### ① Q2 优化模型（5.2.3）—— 把预测修正接进约束

**修改前**
> 能量平衡约束调整为：`xt + Gt∆t + qt + zt = Lt∆t + ct`（(15)）

**修改后**
> 日前计划以**安全净负荷**为输入，能量平衡约束为：
