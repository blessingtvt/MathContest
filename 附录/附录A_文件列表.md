# 附录A　文件列表

> 本附录为 2026 高教社杯 C 题「微网与外部电网电力调控策略」的支撑材料，按 `data / code / results` 三类组织。
## data/　预处理数据

| 文件名 | 功能描述 |
|---|---|
| 附件1_clean.csv | 附件1 清洗后数据：代表日恒定购电价、负荷、光伏 |
| 附件2_load_clean.csv | 附件2 清洗后负荷数据（365 天 × 144 个 10min 区间） |
| 附件2_pv_clean.csv | 附件2 清洗后实际光伏数据（365 天 × 144 区间） |
| 附件3_clean.csv | 附件3 清洗后光伏预报数据（4 个发布时点/天） |
| 附件4_clean.csv | 附件4 清洗后波动购电价数据（365 天 × 144 区间） |
| cleaned_data.pkl | 上述清洗数据的统一 pickle 打包（含物理/费用参数 params，各问模型共同输入） |

## code/　关键模型代码

| 文件名 | 功能描述 |
|---|---|
| common.py | 共享模型核心：单日/全年 LP、无储能与规则套利基线、Q3 滚动 MPC 组件 |
| q1_main.py | Q1 主模型 M1：代表日静态线性规划 LP |
| q2_main.py | Q2 主模型 M2：逐日滚动 LP + 净负荷自预报（7 天加权）+ 80 分位按星期分桶风险修正 |
| q3_main.py | Q3 主模型 M3：滚动 MPC（0:00 计划 + 6/12/18 调整）+ 分段计费 + issue 80 分位光伏修正 |
| q4_main.py | Q4 主模型 M4：波动电价 p_{d,t}  Q2/Q3 最终模型 |

## results/　各问结果

| 文件名 | 功能描述 |
|---|---|
| result1.xlsx | Q1 答案：代表日计划购电量、充放电量、储电量（0:00/24:00） |
| result2.xlsx | Q2 答案：全年计划购电量、充放电量、紧急购电量（334 天） |
| result3.xlsx | Q3 答案：全年计划购电量、调整购电量、充放电量、紧急购电量 |
| result4-2.xlsx | Q4 对应问题二的答案（波动电价下逐日滚动） |
| result4-3.xlsx | Q4 对应问题三的答案（波动电价下滚动 MPC） |
| q2_answer_tables.md | Q2 指定日期结果表（表1 购电量 / 表2 充放电 / 表3 紧急购电） |
| q3_answer_tables.md | Q3 指定日期结果表 |
| q4_answer_tables.md | Q4 结果表（方案对比 / 成本分解 / 恒定 vs 波动 / q 敏感性） |
