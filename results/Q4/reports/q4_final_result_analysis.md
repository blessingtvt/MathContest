# Q4 最终结果分析（波动电价下重解 Q2/Q3）

## 1. 主模型与基线对比

波动电价（附件4）下，主模型 M4 完全继承 Q2/Q3 最终模型、仅将电价 `p_t → p_{d,t}`。报告期（2025-02-01 ~ 2025-12-31）总购电费（元）：

| 方案 | 储能 | 预报 | 日闭合 | 总购电费 |
|---|---|---|---|---|
| B（诊断·全局下界） | 有 | 完美 | 无 | 12,780,883.29 |
| A（诊断·对照） | 有 | 完美 | 有 | 12,830,486.39 |
| **M4·result4-2（主）** | 有 | 自预报 | 有 | **15,231,785.59** |
| B4_ref（诊断·无储能下界） | 无 | 完美 | — | 17,026,782.86 |
| B4（基线） | 无 | 自预报 | — | 18,874,054.20 |

- result4-3（MPC + 分段计费，对应 Q3）：**15,759,231.74** 元（计划 12,929,399.19 + 违约/溢价 1,909,943.19 + 紧急 919,889.36）。
- R4 规则套利基线：17,425,496.32 元。

**价值分解（result4-2）**：
- 储能价值 = B4 − M4 = **3,642,268.60** 元（波动电价下储能收益，占无储能基线 19.3%）；
- 优化价值 = R4 − M4 = **2,193,710.73** 元（LP 相对规则套利的增益）；
- 紧急购电 396,996.49 kWh，弃光率 13.40%；储电量全程落在 [1200, 10800] kWh，日闭合 E(0)=E(144)=6000 验证通过。

## 2. 成本结构分解（核心分析）

result4-2 的总成本可精确分解为"理论最优 + 两层附加成本"（图 fig_q4_2）：

| 层级 | 金额（元） | 说明 |
|---|---|---|
| B 理论最优下界 | 12,780,883.29 | 储能 + 完美预见 + 全年自由结转（不可执行的全局下界） |
| + 日闭合约束成本 | 49,603.10 | 强制 E(0)=E(144)=6000 牺牲的套利空间 |
| + 预报误差附加成本 | 2,401,299.20 | 自预报相对完美预见的损失 |
| = 实际 result4-2 | 15,231,785.59 | |

**结论**：预报误差是 result4-2 相对理论最优的**唯一主要附加成本**（240.1 万元，占 15.8%），日闭合约束成本仅 5.0 万元（可忽略）。

## 3. 预报误差的经济价值分析（重点段落）

**完美预见仅作为诊断基准，不是可落地策略**——它假设未来净负荷完全已知，实际不可执行（规避 round1"误用完美预见作策略"的错误）。

预报误差成本在**储能侧与无储能侧不对称**：

| 场景 | 预报误差成本（元） |
|---|---|
| 无储能侧 B4 − B4_ref | 1,847,271.34 |
| **储能侧 result4-2 − A** | **2,401,299.20** |

**储能系统对预报精度更敏感**：储能侧预报误差损失（240.1 万）比无储能侧（184.7 万）高出 30.0%。原因是储能模型在决策时更激进地利用价格峰谷（低价多充、高价少购），一旦预报偏离，偏差被储能"放大"为错峰购电 + 5 倍紧急购电的双重损失。

**预报优化收益上限 ≈ 240 万元**：若能把自预报精度提升到完美预见，result4-2 可再降 240.1 万元。这是改进预报（更精细的净负荷/光伏预测）在经济上的天花板，为"是否值得投入预报升级"提供了量化依据。

## 4. 恒定电价 vs 波动电价

Q2/Q3 用附件1（固定日内曲线，均值 0.7662），Q4 用附件4（逐日波动，均值同为 0.7662）。result4-2 口径下：

| 指标 | 恒定（附件1） | 波动（附件4） | 变化 |
|---|---|---|---|
| 总购电费 | 14,559,104.58 | 15,231,785.59 | **+672,681.01 (+4.6%)** |
| 基础用电成本（无储能完美预见） | 16,407,319.63¹ | 17,026,782.86 | +619,463.23 (+3.8%) |
| 储能套利空间（无储能完美 − 储能完美日闭合） | 5,927,080.51 | 6,043,567.81 | +116,487.30 (+2.0%) |
| 储能价值 | 3,613,022.84 | 3,642,268.60 | +29,245.76 (+0.8%) |
| 预报误差成本（储能侧） | 2,314,057.67 | 2,401,299.20 | +87,241.53 (+3.8%) |
| 日闭合约束成本 | 16,880.35 | 49,603.10 | +32,722.75 |

¹ 来自 Q2 冻结值 `q2_baseline_B2_ref`。

**结论**：波动电价放大了储能的套利潜力（套利空间 +2.0%），但同时（1）抬升了基础用电成本 +3.8%（附件4 高价时段与高负荷时段正相关，即 TOU 定价效应），（2）放大了预报误差损失 +3.8%。净效应为**总成本 +4.6%**——波动电价对"买方"微网总体不利，储能的套利增益不足以抵消基础成本抬升。

## 5. 稳健性证据（链接）

- **风险分位 q**（`robustness/Q4/q4_robustness_summary.json` R1）：result4-2 最优 q=90（15,126,899.84），q=80 仅高 104,885.75（+0.69%）；result4-3 最优恰为 q=80。故 q=80 设计值近最优、稳健。
- **电价波动幅度**（R2）：放大系数 k∈{0,0.5,1.0,1.5,2.0} 下总成本单调下降（17.17M→12.68M），验证"波动越大套利空间越大"；k>1 出现负价被裁剪至 0.01 以保持 LP 有界。
- **求解可靠性**：所有 daily_lp / stage_lp / full_year_lp 均 success（HiGHS），无 infeasible/unbounded（负价裁剪后）。

## 6. 局限与适用范围

- 完美预见参照（A/B/B4_ref）为**不可执行诊断基准**，仅用于分解成本、量化预报误差，不可作为调度策略。
- 逐日滚动模型假设预报为"7 天加权自预报"，未纳入附件3 外部光伏预报（该信息属 Q3/Q4 MPC 路径）。
- 波动电价按附件4 逐日曲线取用，未建模电价不确定性（电价视为已知）。
- 结论适用于"含储能微网从外部电网购电、日内 10 分钟滚动"的场景。
