# Q3 稳健性分析报告（G4 robustness-checker，round3）

> 主模型 M3：滚动时域 MPC（0:00 计划 + 6/12/18 调整）+ 分段计费线性化 + 日闭合 E(144)=E(0)=6000 + 按 issue 分桶 80 分位光伏风险修正。
> 冻结目标值 M3 = **15,081,833.10 元**（计划 12,370,352.13 / 违约 1,798,546.56 / 紧急 912,934.41）。

## 1. 调整阶段消融 —— 是否需要引入其他预报时刻？

| 纳入的预报/调整时刻 | 报告期总购电费（元） | 相对上一档的边际节省（元） | 边际节省占比 |
|---|---|---|---|
| 仅 0:00（静态，=B3） | 17,398,559.68 |  |  |
| 0:00 + 6:00 | 16,518,867.64 | 879,692.04 | 5.06% |
| 0:00 + 6:00 + 12:00 | 15,146,412.81 | 1,372,454.83 | 8.31% |
| 0:00 + 6:00 + 12:00 + 18:00（=M3） | 15,081,833.10 | 64,579.71 | 0.43% |

- **完美预见下界**（4 个调整时刻但用附件2实际光伏替代预报）：**12,245,046.92 元**（紧急=0）。
- **结论：不需要引入 0/6/12/18 之外的其他预报时刻。** 四个给定时刻的边际价值依次为 88.0 万元、137.2 万元、6.46 万元，呈明显递减；
  第 4 个时刻（18:00）仅带来 6.46 万元（0.43%）的改善，再增加 9:00/15:00/21:00 等中间时刻的边际收益只会更小（每个中间时刻仅能细化 3 小时窗口）。
- 方案B（15.08M）与完美预见下界（12.25M）之间仍有约 2.84M 差距，
  该差距主要来自**预报精度**（尤其 6:00 对上午光伏的系统性高估）而非**预报频次**；提升预报精度比加密预报时刻更有效。

## 2. 分位敏感性（光伏风险修正分位 q）

| 分位 q | 0 | 50 | 60 | 70 | 80 | 90 | 95 | 100 |
|---|---|---|---|---|---|---|---|---|
| 总费用（元） | 40,292,446 | 16,475,452 | 15,748,617 | 15,274,877 | 15,081,833 | 15,223,235 | 15,305,807 | 17,342,968 |

- q=80 取全局最小（15,081,833.10 元），且 q∈[70,90] 曲线平坦（15.08~15.23M），说明 80 分位选择稳健、非过度拟合。
- q=0（不修正）高达 40.29M、q=100（全额修正）17.34M，均显著劣于 q=80，验证保守修正的必要性与适度性。

## 3. 数据扰动稳健性（负荷 / 光伏 ±5%）

| 扰动 | 总费用（元） | 相对基准变化 |
|---|---|---|
| 负荷 +5% | 16,376,591.85 | +1,294,758.75（+8.58%） |
| 负荷 -5% | 13,809,762.39 | -1,272,070.71（-8.43%） |
| 光伏 +5% | 14,762,978.48 | -318,854.62（-2.11%） |
| 光伏 -5% | 15,798,903.05 | +717,069.95（+4.75%） |

- 费用随负荷/光伏扰动近似线性、无断崖：负荷 ±5% 引起约 ±8.5% 费用变化（负荷直接决定购电缺口），光伏 ±5% 仅 ±2~5%（储能与风险修正部分吸收了光伏波动）。
- 各扰动下模型均保持可行、最优值与基准同数量级，结论（储能+MPC+风险修正可显著省钱）稳健成立。

## 4. 预报误差-前瞻时域（支撑结论）

- 光伏预报误差随前瞻时域增长（见 `figures/fig_horizon_error.png`）；6:00 发布的预报对上午时段系统性高估（P80≈1003 kW），12:00 对午后略低估，18:00 后的夜间光伏近零、几乎无可修正空间。
- 这正是 6:00/12:00 调整价值大、18:00 调整价值趋零的原因，进一步支持「无需加密预报时刻」的结论。
