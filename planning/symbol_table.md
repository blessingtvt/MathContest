# 统一符号表（全队唯一权威，禁止自定义符号）

> 适用范围：C题 微网与外部电网电力调控策略，Q1–Q4。
> 所有后续公式、代码、论文必须严格复用本表符号；新增符号须先回填本表并全队确认。
> 时间粒度：10分钟/区间；功率(kW)与电量(kWh)换算：能量 = 功率 × Δt，Δt = 1/6 h。

## 8. 核心关系式（符号一致性基准）

**能量平衡**（区间 t，供电 ≥ 负载）：
```
x_{d,t} + z_{d,t} + G_{d,t}·Δt + q_{d,t}  ≥  L_{d,t}·Δt + c_{d,t}
```
（Q1 无 z；Q1 用 Ĝ_t 代 G，L_t 代 L_{d,t}；Q3/Q4 中 x 为最终购电 = y，见下）

**储能动态**（区间 t 末储电量）：
```
E_{d,t} = E_{d,t-1} + η_c·c_{d,t} − q_{d,t}/η_d
```
约束：E_min ≤ E_{d,t} ≤ E_max；0 ≤ c_{d,t} ≤ P^c_max·Δt；0 ≤ q_{d,t} ≤ P^d_max·Δt。

**购电费用**：
- Q1：`C1 = Σ_t p_t·x_t`
- Q2：`C2 = Σ_{d,t} p_t·(x_{d,t} + 5·z_{d,t})`
- Q3：`C3 = Σ_{d,t} p_t·[ min(x_{d,t}, y_{d,t}) + β_pen·max(x_{d,t}−y_{d,t},0) + γ_pre·max(y_{d,t}−x_{d,t},0) ] + Σ_{d,t} 5·p_t·z_{d,t}`
- Q4：将上式 p_t 替换为 p_{d,t} 分别重算 Q2、Q3。

## 9. 冲突消解与约定

- **负荷两套符号**：L_t（附件1 恒定日，仅 Q1）与 L_{d,t}（附件2 实际，Q2–Q4）语义不同，分别保留，不合并。
- **电价两套符号**：p_t（附件1 恒定）与 p_{d,t}（附件4 波动）语义不同，分别保留。
- **光伏三套符号**：Ĝ_t（Q1 单日预测）、Ĝ_{d,s,h}（Q3/Q4 滚动预报）、G_{d,t}（实际），禁止混用。
- **充/放电电量** c、q 采用"电网侧输入/负载侧输出"口径，效率 η_c、η_d 已在动态式中消解，费用只对购电量 x/y/z 计，不重复计储能。
- 计费口径（min/max 结构）与区间功率对应方式属 HD4/HD1，G2 前由人类确认，确认后本表相应注释更新，不新增符号。
