## 三、跨问题冲突与一致性检查

- **负荷口径**：Q1 用 L_t（恒定），Q2–Q4 用 L_{d,t}（实际）。二者不得混用；Q1 为基准、Q2–Q4 为实际波动，一致性由 S1 解释（L_t=均值）。
- **电价口径**：Q1–Q3 用 p_t（恒定），Q4 用 p_{d,t}（波动）。Q4 与 Q2/Q3 的差异**仅**在费用函数电价替换，储能/负荷/光伏结构不变。
- **光伏口径**：Q1 用 Ĝ_t（预测），Q2 用 G_{d,t}（实际，完美预见），Q3/Q4 用 Ĝ_{d,s,h}（滚动预报）+ G_{d,t}（实际结算）。三类符号严格区分。
- **充放电效率 A6** 影响储能动态式，进而影响所有 Qx 的最优充放电策略，属全局 load-bearing 假设，须优先确认。
