## 主模型 M2：逐日滚动 LP + 自预报 + 风险修正（时间因果，不跨日看未来）
1. 净负荷 `N = load − pv`；`Nhat, Eerr = netload_forecast(N)`：7 天加权平均 w=[0.3,0.2,0.15,0.12,0.1,0.08,0.05]。
2. `for d in 31..364:` 历史误差 80 分位 `e80 = percentile(Eerr[7:d], 80)`（仅用 d 之前数据，因果）。
3. `Nsafe = Nhat[d] + e80`；`daily_lp(price, Nsafe, zeros(T), E0=6000, terminal_eq=True, E_term=6000)`（净负荷口径，日末循环）。
4. 紧急购电 `z_d = max(N_real·Δt + c_d − x_d − q_d, 0)`。
5. 报告期费用 = Σ price·Xr + 5·Σ price·Zr。

> 与全年联合不同：每天只解当天 LP（单日变量 577 个），无跨日耦合，符合"每天 0:00 制定当天计划"的题设；全年联合已降为事后下界诊断参考。日末循环 S_144=S_0=6000（用户指定，避免跨日自由终态）。

## 基线（同信息集：自预报 + 80分位风险修正 + 紧急购电）
- **B2 无储能**：报告期逐日 `no_storage_forecast(price, Nsafe, N_real)` 求和。
- **R2 规则套利**：逐日 `rule_forecast_day`（`rule_arbitrage` + Nsafe 净负荷 + 紧急），储能跨日结转。
- **B2_ref 无储能·完美预见**：`no_storage(price, load[d], pv[d])`（诊断参考，量化预报误差成本）。

## 成本优化实验（2026-09-12）

新增代码：`code/Q2/q2_optimized.py`。该代码不改变逐日滚动 LP、净负荷自预报、紧急购电、储能边界或日末循环，只扩展计划侧目标和风险修正计算，并将结果写入 `results/Q2/experiments/optimization/optimization_summary.json`。

### 目标函数与新增参数

计划侧 LP 使用弃光松弛变量 `r_{d,t}`：

\[
r_{d,t}\ge G^{f}_{d,t}\Delta t+x_{d,t}+q_{d,t}-L^{f}_{d,t}\Delta t-c_{d,t},\qquad r_{d,t}\ge0.
\]

其中 `G^f,L^f` 是决策时可获得的光伏/负荷预测；实际结算仍使用附件2实际负荷和光伏，紧急购电定义保持不变。扩展 LP 目标为

\[
\min\sum_t p_t x_{d,t}+\lambda\sum_t r_{d,t}.
\]

新增参数为 `lambda ∈ {0, 0.01, 0.05, 0.1, 0.5, 1.0}`，单位为元/kWh。风险修正支持 `fixed`、`month`、`season` 三种历史误差分组方式，并测试固定 `q=70/80/90` 与月度/季节 `q=80`。

综合费用最优方案仍为 `lambda=0, fixed q=80`，即原模型。最小的非零惩罚 `lambda=0.01` 将总费用提高至 17,745,736.46 元，紧急购电量增至 494,891.06 kWh，仅减少弃光 1,355.17 kWh；`lambda=0.05/0.1/0.5/1.0` 得到相同调度结果。说明在当前约束和费用口径下，弃光惩罚没有足够的可调节空间，且其减少的预测侧弃光不足以抵消紧急购电增加。

所有优化实验的储电量均满足 `1200≤E_t≤10800`，并满足每日 `E_{d,24}=E_{d,0}=6000`。

### 判断与论文建议

- 就降低总费用而言，两种方案均未优于原 M2；方案1的非零 `lambda` 只改善弃光，不改善经济性，方案2的月度/季节 q=80 反而增加费用。
- 因此不建议把这两种未经进一步改造的版本作为论文最终主模型；论文最终模型继续采用固定 q=80 的 M2，并将上述结果作为负向敏感性实验。
- 论文可写为：

  > 在 M2 的逐日滚动 LP 中引入计划侧弃光松弛变量，并以 `λΣr_{d,t}` 加入目标函数；同时按月份或季节对历史净负荷预测误差重新估计风险分位。实验显示，在日末 SOC 闭合、无弃光收益且紧急购电保留的设定下，非零弃光惩罚会增加紧急购电成本，动态风险分组也未降低总费用。因此最终模型保留固定 80 分位风险修正，并将弃光惩罚与动态风险作为稳健性检验。

## 严格因果场景 LP 优化（2026-09-12）

根据 Q2 题意，未使用完美预见、附件3、当天未来实际值或全年联合规划。新增 `code/Q2/q2_causal_scenario.py`，每天 0:00 仅使用此前历史数据，生成 5 个净负荷误差场景，并在单日 LP 中直接计入场景紧急购电费用与 CVaR 项。

最终采用的历史预测为：

\[
\hat N_d=0.75\hat N_d^{\mathrm{uniform7}}+0.25\hat N_d^{\mathrm{weekday4}},
\]

其中 `uniform7` 为前 7 天同一时刻净负荷均值，`weekday4` 为前 4 个同星期日的加权均值（权重 0.4/0.3/0.2/0.1）。误差场景使用历史样本的 10/30/50/70/90 分位，概率为 0.1/0.2/0.4/0.2/0.1。计划变量在场景间共享，紧急购电变量按场景展开。

推荐参数为 `rho=0.2`、`beta=0.90`。该方案严格采用因果历史信息，复算结果为：

| 指标 | 原 M2 | 因果场景 LP | 改善 |
|---|---:|---:|---:|
| 总费用（元） | 17,741,097.14 | **14,565,811.29** | **−17.92%** |
| 计划购电费用（元） | 15,739,922.23 | 13,420,805.79 | −2,319,116.44 |
| 紧急购电费用（元） | 2,001,174.91 | 1,145,005.50 | −856,169.41 |
| 紧急购电量（kWh） | 493,945.00 | 293,193.98 | −200,751.02 |
| 弃光量（kWh） | 6,406,246.78 | 3,416,275.42 | −2,989,971.36 |
| 弃光率 | 33.5953% | 17.9154% | −15.6799 个百分点 |

储电量复核范围为 `1200–10800 kWh`，每天末端均回到 `6000 kWh`。相对于原 M2，该方案总费用减少 3,175,285.85 元；其中紧急购电费用下降是主要来源，说明把紧急购电成本前置到 LP 目标函数有效。

本次优化结果写入 `results/Q2/experiments/optimization/blend25_scenario.json` 和 `results/Q2/experiments/optimization/causal_scenario_summary.json`。该方案可以作为 Q2 的改进模型；论文中应明确说明所有预测、误差场景和参数选择均遵循时间因果性，不能使用当天实际未来值。
