# Q4 最终方法说明（论文模型章节底稿）

> 方法选型依据人类决策 `q4_method_choice_r2`（完全继承 Q2/Q3 最终模型，仅换电价）。本文档自含，供论文写作直接取用；所有数值引用 `results/Q4/reports/frozen_numbers.json`。

## 1. 目标与范围

在**波动电价**（附件4，逐日逐时段变化）下，求解微网从外部电网购电的**最优调控策略**，最小化报告期（2025-02-01 ~ 2025-12-31，334 天）总购电费。Q4 本质是把 Q2（无日前外部预报、储能套利）与 Q3（滚动调整 + 分段计费）两套模型在"电价逐日波动"这一新条件下重新求解，考察电价波动对储能价值与预报误差成本的影响。

## 2. 假设

- 储能参数不变：容量 E∈[1200, 10800] kWh，功率 P≤5000 kW，充放效率 η_c=η_d=0.9，初始 E0=6000 kWh，容量 C=12000 kWh（延续 Q2/Q3）。
- 电价 `p_{d,t}` 逐日逐时段已知（附件4 提供，均值 0.7662 = 附件1 恒定价均值）。
- result4-2 信息集与 Q2 一致：**仅用附件2 历史净负荷**自预报，不用附件3 外部光伏预报。
- result4-3 信息集与 Q3 一致：**用附件3 光伏滚动预报**（0/6/12/18 四次发布），按 issue 分桶做光伏风险修正。

## 3. 符号与单位

| 符号 | 含义 | 单位 |
|---|---|---|
| T=144 | 每日 10 分钟区间数 | — |
| Δt=1/6 | 区间时长 | h |
| `p_{d,t}` | 波动电价 | 元/kWh |
| `L_t, G_t` | 负载 / 光伏功率 | kW |
| `N_t = L_t − G_t` | 净负荷 | kW |

| `N̂_d, e_q(dow)` | 净负荷自预报 / 星期分位风险修正 | kW |

## 4. 数学建模

### 4.1 result4-2（继承 Q2：逐日滚动 LP）

**预报**：净负荷 7 天加权自预报 `N̂_d = Σ_{k=0}^{6} w_k N_{d−1−k}`，权重 `w=[0.3,0.2,0.15,0.12,0.1,0.08,0.05]`；再加按星期分桶的 80 分位风险修正 `e_80(dow)`（仅用当日之前同星期的历史误差，因果），得到安全预报 `N^safe_d = N̂_d + e_80(dow)`。

**逐日 LP**（每日独立，日闭合 E(0)=E(144)=6000）：

```
min  Σ_t p_{d,t} · x_t
s.t. x_t + q_t − c_t ≥ N^safe_t · Δt        (能量平衡, 预报口径)
     c_t ≤ P_max·Δt,  q_t ≤ P_max·Δt        (功率上限)
     E_{t+1} = E_t + η_c c_t − q_t/η_d       (储能动态)
     E_0 = E_144 = 6000,  E_t ∈ [1200, 10800]
     x_t, c_t, q_t ≥ 0
```

**结算**（用真实净负荷）：紧急购电 `z_t = max(N_t·Δt + c_t − x_t − q_t, 0)`，费用 `C_42 = Σ p_{d,t}(x_t + 5 z_t)`。

### 4.2 result4-3（继承 Q3：滚动 MPC + 分段计费）

**滚动时域**：0:00 制定全天计划，6/12/18 点各调整一次（每次只重优化剩余时段）。各 issue 用光伏预报 `Ĝ_s` 减去按 issue 分桶的 80 分位光伏高估修正 `δ_s`（δ=[0, 1005.49, −6.27, 0] kW），得到保守预报 `Ĝ^safe = clip0(Ĝ − δ)`。

**分段计费**（调整量 y 相对计划 x 分两段）：计划内 0.5、溢价 1.5（违约 0.5），即
`费用 = Σ p_{d,t}[min(x,y) + 0.5·max(x−y,0) + 1.5·max(y−x,0)] + Σ 5 p_{d,t} z_t`。
每段仍日闭合 E(144)=6000；结算用附件2 实际光伏。

## 5. 输入 / 输出 / 目标 / 约束

- 输入：`data_clean/cleaned_data.pkl`（附件1/2/3/4 清洗数据）；模板 `data_raw/附件5/result4-2.xlsx`、`result4-3.xlsx`。
- 输出：`results/Q4/result4-2.xlsx`（计划购电/充放电/紧急购电）、`result4-3.xlsx`（计划/调整/充放电/紧急购电）。
- 目标：最小化报告期总购电费。
- 约束：能量平衡、储能动态与容量/功率边界、日闭合、非负。

## 6. 求解过程

Python + scipy linprog（HiGHS），SEED=2026（确定性 LP，无随机量）。result4-2 逐日求解 144 区间 LP；result4-3 逐日求解 1 次计划 LP + 3 次调整 LP（分段计费线性化）。全年滚动，warmup 31 天后进入报告期 334 天。

## 7. 基线与其有效性

| 基线 | 定义 | 有效性 |

## 9. 验证 / 稳健性 / 局限

- **求解可靠性**：全部 LP success，日闭合、储能边界验证通过。
