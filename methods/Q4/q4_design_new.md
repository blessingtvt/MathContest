# Q4 方案设计：波动电价下重解问题2 / 问题3

> 依据：题目「实际上，外网的电价也是实时波动的。请针对波动电价，建立微网当天购电策略的数学模型。根据附件2负载与光伏、附件3预报和附件4电价数据，在波动电价下重新计算问题2和问题3。完整购电策略分别保存到 result4-2.xlsx（对应问题2）和 result4-3.xlsx（对应问题3）。」
> 口径基准：**Q2 = round4（冻结 14,559,104.58 元）**；**Q3 = round4 块级（`code/Q3/q3_optimized.py`，issue×执行块因果分位修正，q=80 冻结主值 → 14,049,999.28 元；argmin q=85 → 14,020,104.48 仅作敏感性参照）**
> 报告期：2025-02-01 ~ 2025-12-31（334 天，1 月预热）；储能参数、单位、10 min 粒度不变。

---

## 0 一句话设计

**Q4 = 骨架完全继承 Q2 round4 与 Q3(block-q80)，唯一变化是目标函数里的 $p_t$ 换成附件4 的 $p_{d,t}$**；把"电价波动"带来的新增经济价值（星期效应/跨日套利/极端低价）用**同口径对照实验**单独量化，而不是改动骨架。

## 1 先决：三个必须写死的口径

| # | 口径 | 默认取值（本方案） | 备选（作为对照实验） |
|---|---|---|---|
| C1 | **电价信息集** | **当天逐时段已知**（日前出清价口径）：0:00 计划、6/12/18 调整均可使用当天真实 $p_{d,t}$ | 「实时未知」：用因果电价自预报（分时曲线 × 星期乘子的历史分位）替代 → 实验 E4-3 |
| C2 | **储能时间口径** | **日闭合** $E(144)=E(0)=6000$（与 Q2 round4 / Q3 一致，保证可比） | 「跨日自由结转」（仅年末闭合）→ 实验 E4-2 |
| C3 | **光伏风险修正** | 直接继承：Q2 用按星期分桶 e80[dow]；Q3 用 issue×执行块因果分位（q=80 冻结主值，MIN_HIST=7，只修正本阶段执行的 6 h 块；argmin q=85） | q 重扫 → 实验 E4-4；价格加权分位 → 实验 E4-1 |

**C1 的判别依据（写进论文）**：题目把附件4 作为"**数据**"与附件2/3 并列给出，且要求产出"完整购电策略"（含全天 计划/调整 表），故按"当天电价已知（日前市场出清价）"建模；"实时未知"作为稳健性情景，量化**电价预测误差成本**——与 Q2 的净负荷自预报、Q3 的光伏预报共同构成"三重不确定性"叙事。

**C3 的关键理论依据（可在论文中强调）**：紧急购电价 $5p_{d,t}$、计划/调整价 $p_{d,t}$（含 0.5/1.5 倍），**分子分母同乘 $p_{d,t}$，报童临界比 $\Pr^*$ 与 $p_{d,t}$ 无关** → Q2 的 $q=0.80\ (=\tfrac{5-1}{5})$ 与 Q3 的 $q=0.80$ **在结构上可原样继承**（Q3 经验 argmin 略右移至 $q=0.85$），只需重扫确认经验最优未漂移（波动电价下"价格—缺电同频"corr=0.508 可能使经验最优略偏）。

## 2 附件4 的实测结构（决定了新增价值在哪里）

$$p_{d,t}\;\approx\;\underbrace{p^{(1)}_t}_{\text{附件1 分时曲线}}\times\underbrace{m_d}_{\text{每日水平(星期效应)}}\times\underbrace{(1+\varepsilon_{d,t})}_{\approx11\%}$$

| 事实 | 数值 | 对建模的含义 |
|---|---|---|
| 附件4 分时均值曲线 vs 附件1 电价曲线 | **相关 1.0000（数值一致）** | **日内形状与 Q2/Q3 完全相同** |
| 每日乘子 $m_d$ | 0.688~1.213，std 0.140 | 日间只有水平差异 |
| $m_d$ 自相关 | lag1 0.488，**lag7 0.964** | **本质是星期效应**（周五/六 ≈ 其他日 0.79） |
| 方差分解 | 时段形状 84.4% / 日间 15.6% | 新增信息几乎全在"日间水平" |
| 日内价差(前25%−后25%) | 0.757 元/kWh | 储能可用 9600 kWh ⇒ 日内套利上限 ≈ 5890 元/天 ≈ **197 万元/年**；附件1 同法 190.8 万元 → **日内套利价值几乎不变** |
| 极端低价 | <0.1 元 2 天、<0.2 元 23 天、>1.5 元 78 天 | 稀疏尖峰，不是结构性规律 |
| corr(价, 负荷) / corr(价, 光伏) | +0.508 / +0.028 | **高价与高负荷同时发生 → 缺电代价被放大** |

**三条推论**（Q4 设计主线）：
1. 日内套利价值与 Q2/Q3 基本相同 → 总费用上升主要来自"日间水平波动"，而非日内形状；
2. **真正新增的经济价值是"星期效应/跨日套利"**，而 Q2/Q3 的日闭合恰好禁止它（旧版 Q4 实测日闭合代价 ≈ 4.96 万元）→ 必须用实验量化（E4-2）；
3. 只有 11% 的时段噪声是"不可预测"的 → C1 若取"未知"，用分时曲线×星期乘子即可解释大部分，电价预报误差成本有限。

## 3 模型 A：result4-2（对应问题2，逐日滚动 LP）

**与 Q2 round4 同构，仅电价改动**：

```
净负荷      N_{d,t} = L_{d,t} − G_{d,t}
自预报      N̂_d = Σ_{k=1..7} w_k·N_{d−k},  w=[0.3,0.2,0.15,0.12,0.1,0.08,0.05]
风险修正    e80[dow] = P80{ e_{d',t}=N_{d',t}−N̂_{d',t} : d'<d, dow(d')=dow(d) }   (因果, 按星期分桶)
安全净负荷  N^safe = N̂_d + e80[dow]
逐日 LP     min Σ_t p_{d,t}·x_t
            s.t. x_t + q_t − c_t ≥ N^safe_t·Δt ; c,q ≤ P_max·Δt
                 E_{t+1}=E_t+η_c c_t−q_t/η_d ; E∈[1200,10800] ; E(144)=E(0)=6000
结算        z_t = max(N_{d,t}Δt + c_t − x_t − q_t, 0) →  费用 = Σ p_{d,t}(x_t + 5 z_t)
```

**Q4 相对 Q2 的注意点**
- 目标系数变为 $p_{d,t}$（逐日逐时段），LP 结构与变量完全不变；
- 高价日常伴随高负荷 → 风险修正分位可做"价格加权"版本（E4-1）确认 $q=0.80$ 仍近最优；
- 输出 `result4-2.xlsx`：**计划购电量 / 充放电量 / 紧急购电量**（3 sheet，格式同模板）。

## 4 模型 B：result4-3（对应问题3，滚动 MPC + 分段计费）

**与 Q3 `q3_optimized.py`（块级 q=80 冻结主值）同构，仅电价改动**：

```
风险修正    over[d,s,j] = fc_s[d, j//6] − pv[d, 36s+j],  j=0..35     (issue s 实际执行的 6h 块)
            δ[s,j] = P85{ over[:,s,j] : 7 ≤ d' < d }                 (因果, 扩张窗口, MIN_HIST=7)
保守预报    Ĝ_safe = clip0( Ĝ_s − δ[s] ), 只作用于本阶段执行的 36 个区间
滚动 MPC    0:00  plan : daily_lp(p_{d}, L_d, Ĝ^safe_0, E_carry, 日闭合)
            6/12/18 adj: stage_lp(p_{d}[sl:], ..., x[sl:], E_prev, 日闭合),  si=36/72/108
            拼接 y=[x[:36], y1[:36], y2[:36], y3[:36]]，储能同拼接
分段计费    Σ p_{d,t}[min(x,y) + 0.5(x−y)^+ + 1.5(y−x)^+] + 5Σ p_{d,t} z_t
            z_t = max(LΔt + c − y − G_actual·Δt − q, 0)          (结算用附件2 实际光伏)
```

**Q4 相对 Q3 的注意点**
- δ 由"预报−实际光伏"的历史分位给出，**与电价无关** → 形式不变；但"哪个时段的缺电更贵"变了 → 重扫 q（E4-4）；
- 12:00 阶段的剩余时段包含晚高峰（19-20 时 1.27~1.35 元/kWh）→ 调整时刻的边际价值需重算（E4-5）；
- 输出 `result4-3.xlsx`：**计划 / 调整 / 充放电 / 紧急购电**（4 sheet）。

## 5 基线与诊断（必须同信息集、同计费、同日闭合）

| 编号 | 定义 | 用途 |
|---|---|---|
| **B4** | 无储能 + 自预报 + e80[dow] + 紧急购电 | 储能价值 = B4 − M4 |
| **R4** | 规则峰谷套利 + 同信息集 + **同结算口径**（必须走与主模型一致的结算；不得直接调用 `rule_arbitrage` 了事） | 优化价值 = R4 − M4 |
| **B4_ref** | 无储能 + 完美预见净负荷（诊断下界，不可执行） | 预报误差成本 |
| 诊断 A | 储能 + 完美预见 + 日闭合（与 result4-2 同约束） | 分解"日闭合约束成本" |
| 诊断 B | 储能 + 完美预见 + 跨日自由结转 | 全局理论下界 |

> **round1 的教训**：当时 R4 用 `rule_arbitrage`（无调整、无紧急结算）计算，与 result4-3 口径不同，导致"主模型 17.71M 比基线 15.79M 还差"的假象。Q4 的基线必须与主模型**逐项同口径**。

## 7 校核清单（验收标准）

1. **口径对齐**：E4-0 精确复现 Q2 与 Q3 的冻结值（±0.01 元）；
2. **约束**：$E\in[1200,10800]$ 全年越界 0 次；每日 $E(0)=E(144)=6000$；$c,q\le 5000$ kW；充放同时区间 = 0；$z$ 与弃光互斥（同时 >0 = 0）；
3. **恒等式**：plan + penalty/premium + emergency = total（逐项与 run_summary 吻合 <0.01）；
4. **基线排序**：M4 ≤ 其余（B4_ref / R4 / B4 依次更差）；若 M4 被某基线超越，先查口径；
5. **交付物**：`result4-2.xlsx`(3 sheet) / `result4-3.xlsx`(4 sheet) 行列与模板一致，指定日期行齐全；
6. **口径同步提醒（已解决 ✓）**：Q3 已冻结为 **round4 块级 q=80 = 14,049,999.28**（`results/Q3/reports/frozen_numbers.json`）。`code/Q4/q4_main.py` 的 result4-3 已由 round3 标量 δ 升级为**块级 `block_delta`（issue×执行块 逐区间 80 分位，4×36）**，与 Q3 最终模型对齐；Q4 冻结主值 result4-3 = **14,694,112.99**（round3 块级 q=80），排序恢复 result4-3 < result4-2，消除"Q4-3 反超 Q4-2"的假象（详见 `results/Q4/reports/freeze_change_log.md`）。

## 11 风险与已知坑

1. **口径不一致**（round1 的最大问题）：result4-2 误用 `full_year_lp`（完美预见）、result4-3 漏光伏修正、基线不同结算 —— 本方案用 E4-0 回归把这三条全部钉死；
2. **Q3 基准漂移**：Q3 从 round3 标量（15.08M）换到 round4 块级（q=80 冻结 14.05M）后，Q4-3 必须重算，不能沿用旧锚点；
3. **`q3_optimized.py` 的 SOC 统计是桩**：其 `run()` 里 `emin/emax` 只对 `E0_INIT` 取极值（恒 6000），Q4 实现时**必须记录真实储能轨迹**（否则 SOC 波动指标无效）；
4. **极端低价**：0.0076 元区间会让"多买/多充"近乎免费、0.5p 违约也近乎免费 → 计划可安全抬高；需检查解不退化（E4-7）；
5. **优化实验的比较基准**：沿用 Q2 的教训——任何实验都必须与主模型**同基准**比较，否则会出现"看起来更好"的假象（`q2_optimized.py` 的 λ 实验就是被自身基准差异掩盖的负结果）。
