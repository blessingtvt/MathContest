# Q3 模型合理性分析（round3，已修复 round1 储能倒空缺陷）

> **数据来源**：附件1 分时电价（0.37~1.40 元/kWh）+ 附件2 实际负载/光伏 + 附件3 滚动光伏预报（0/6/12/18）。
> **方法**：滚动时域 MPC + 分段计费线性化 + 日闭合 E(144)=E(0)=6000 + 按 issue 分桶 80 分位光伏风险修正。
> **报告期**：2025-02-01 ~ 2025-12-31（334 天，1 月预热）。
> **计费口径**（HD4）：费用 = p·min(x,y) + 0.5p·max(x−y,0) + 1.5p·max(y−x,0)，紧急购电 5 倍价（用附件2 实际光伏结算）。
> 全部数值为 round3 独立复核结果，与 `frozen_numbers.json` 逐项吻合。

## 一、约束条件检验（必须）

### 1.1 功率平衡检验 —— 「供给(含紧急) ≥ 需求」

每区间：$\text{缺口}_t=L_t\Delta t+c_t-y_t-G^{\text{实际}}_t\Delta t-q_t$，$z_t=\max(\text{缺口}_t,0)$。

| 检验项 | 数值 | 结论 |
| --- | --- | --- |
| 总紧急购电能量 | 245,793.57 kWh | 预报低估光伏时触发 |
| 欠供区间数（供给仍 < 需求） | **0** | 紧急购电恰好补足，无欠供 |
| 紧急购电与弃光互斥（同时 >0 的区间） | **0** | 欠供与富余不并存 |
| 弃光电量（实际光伏富余） | 2,812,018.61 kWh（弃光率 14.75%） | 预报高估光伏时弃光 |

**结论**：供给（计划/调整 + 实际光伏 + 放电 + 紧急）≥ 需求恒成立，欠供 = 0；紧急与弃光互斥、机制自洽。功率平衡成立。

### 1.2 储能容量检验 —— ✅ 已修复（round3）

| 检验项 | 数值 | 结论 |
| --- | --- | --- |
| 每日 0:00 储电量 $E(0)$ | min = max = **6000** | 与初始态一致，跨日连续 |
| 每日 24:00 储电量 $E(144)$ | min = max = **6000** | 日闭合约束 $E(144)=E(0)$ 成立 |
| 全区间储电量范围 | **[1200, 10800] kWh**，越界 0 | 边界内，且触顶/触底均在允许范围 |

**修复说明**：round1 中 `daily_lp`/`stage_lp` 以 `terminal_eq=False` 求解，优化器把储能每日倒空至 1200（末端短视），丧失跨日价值。round3 对每段 LP 强制 `terminal_eq=True, E_term=6000`，实现日闭合 $E(0)=E(144)=6000$，储能跨日连续、保留"夜充晨放"套利。修复后含储能方案（15.08M）显著优于无储能（见 §2.2），round1 的横向异常消失。

## 二、结果合理性分析

### 2.1 储能循环合理性 —— ✅ 成立

每日 $E(0)=E(144)=6000$，储能日内"低价充电、高价放电"（充电集中在夜/清晨低电价段，放电集中在高电价峰段），日终回到 6000，形成**可重复的日周期闭环**，与 Q1 日闭合、Q2 连续储能一致。

### 2.2 优化效果与基线排序

| 方案 | 总购电费（元） | 说明 |
| --- | --- | --- |
| **M3（主模型）** | **15,081,833.10** | 滚动 MPC + 修正 + 储能 |
| B3_ref（无储能·完美预见下界） | 16,407,319.63 | 无储能但已知实际光伏 |
| B3（静态不调整） | 17,398,559.68 | 仅 0:00 计划 |
| R3（规则套利） | 17,753,485.91 | 贪心规则 |
| NS_fc（无储能·附件3预报） | 20,128,453.40 | 无储能 + 预报 |

- **排序成立**：M3 < B3_ref < B3 < R3 < NS_fc。
- **调整价值**（B3−M3）= 2,316,726.58 元；**优化价值**（R3−M3）= 2,671,652.81 元；**储能价值**（NS_fc−M3）= 5,046,620.30 元；**修正价值** = 1,888,407.69 元。
- **强结论**：M3 用**有偏**预报，仍低于**无储能完美预见**下界 1,325,486.53 元——储能 + 滚动调整 + 风险修正的联合价值足以抵消光伏预报误差。这与 round1"含储能反而更贵"的缺陷结论形成鲜明对比，证明修复有效。

### 2.3 弃光与紧急购电的权衡

- 未修正方案 A：紧急购电 4,170,246.79 元、弃光 2,103,623.51 kWh。
- 修正方案 B：紧急购电 912,934.41 元、弃光 2,812,018.61 kWh。
- 修正以"增加弃光（低成本）"换取"大幅减少 5 倍紧急购电（高成本）"，净节省 1,888,407.69 元——符合"把高估缺口转成弃光而非紧急"的设计意图。
