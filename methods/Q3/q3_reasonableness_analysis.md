# Q3 模型合理性分析

> **数据来源**：附件1 恒定电价 + 附件2 实际负载/光伏 + 附件3 滚动光伏预报（0/6/12/18 四个时刻），滚动时域 MPC + 分段计费线性化。
> **报告期**：2025-02-01 ~ 2025-12-31；1 月为预热期（HD5）。
> **计费口径**（HD4）：计划 x、调整 y，费用 = p·min(x,y) + 0.5p·max(x−y,0) + 1.5p·max(y−x,0)，紧急购电 5 倍价（用附件2 实际光伏结算）。

## 一、约束条件检验（必须）

### 1.1 功率平衡检验 —— 「供给(含紧急) ≥ 需求」

用附件2 **实际光伏**结算，每区间定义：

$$
\text{缺口}_t = L_t\Delta t + c_t - y_t - G^{\text{实际}}_t\Delta t - q_t,\qquad
z_t = \max(\text{缺口}_t, 0)
$$

| 检验项 | 数值 | 结论 |
| --- | --- | --- |
| 紧急购电区间数（缺口>0） | 10571 / 48096 | 预报低估光伏时触发 |
| 总紧急购电能量 | 976860 kWh | — |
| 欠供区间数（供给仍 < 需求） | 0 | 紧急购电恰好补足，无欠供 |
| z 与弃光互斥（同时 >0 的区间） | 0 | 正确：欠供与富余不并存 |
| 弃光区间数 / 弃光电量（实际光伏富余） | 16745 / 2103298 kWh | 预报高估光伏时弃光 |

**结论**：供给（计划+实际光伏+放电+紧急）≥ 需求恒成立，欠供 = 0；紧急购电与弃光互斥、机制自洽。功率平衡成立。

### 1.2 储能容量检验 —— ⚠️ 发现严重问题

| 检验项 | 数值 | 结论 |
| --- | --- | --- |
| 每日 0:00 储电量 E₀ | **min = max = 1200** | ⚠️ 全年恒为下界 |
| 每日 24:00 储电量 E₂₄ | **min = max = 1200** | ⚠️ 全年恒为下界 |
| 越界点数 | 0 | 边界内（但贴在 1200 下界） |

**⚠️ 根本问题：储能每天都被"倒空"到 1200（下界），全年 0:00 与 24:00 的储电量恒为 1200，从不回到初始 6000。**

**根因**：`q3_mpc_day` 中 `daily_lp`/`stage_lp` 均以 `terminal_eq=False` 求解——单日/单阶段滚动优化**没有储能终态约束、也没有储能期末残值**，于是优化器把储能当天放空（储能若留到 24:00 无价值，不如放电抵消购电）。这是滚动时域的"末端短视"。

**后果**：
1. 储能从不跨日携带能量（每晚放空），丧失"夜充晨放"的跨日套利与早高峰支撑能力；
2. 次日清晨储能恒为空，早高峰只能靠购电，推高购电与紧急购电成本；
3. 与 Q1（日闭合 E(0)=E(24)）、Q2（储能跨日连续）自相矛盾。

## 二、结果合理性分析（建议）

### 2.1 储能循环合理性 —— ⚠️ 不成立

- 每日 E(0)=E(24)=1200（储能终态被"倒空"到下限，而非回到 6000 初始态）
- 储能日内仍有充放（充电/放电功率均触及 5000 kW），但**终态闭合到 1200 而非 6000**，破坏"日周期可重复"的闭环要求。

### 2.2 优化效果验证（推荐）

| 方案 | 报告期总购电费 | 说明 |
| --- | --- | --- |
| 静态不调整 B3（有储能） | 17400028.28 元 | 仅 0:00 计划并执行 |
| 规则套利 R3（有储能） | 18065256.61 元 | 滚动预报贪心 |
| **主模型 M3（MPC）** | **16972663.03 元** | 含违约/溢价/紧急 |

- 调整价值（M3 vs B3）= 427365.25 元（滚动调整相对静态略有收益）
- 优化价值（M3 vs R3）= 1092593.58 元

**⚠️ 横向异常**：Q2 无储能基准 B2 = 16407319.63 元（同电价、同负载/光伏、完美预见）。M3 = 16972663.03 元 **竟然高于无储能**——引入储能 + 滚动调整后总成本反而不降。这正是储能被每天倒空、且紧急购电（5 倍价）叠加预报误差共同作用的结果，印证了 1.2 的储能 bug 造成的实质损失。

---

## 综合结论

Q3 模型**存在严重缺陷**：滚动优化无储能终态约束，导致储能**每天倒空至 1200**、丧失跨日价值，最终含储能方案（1697 万元）反而贵于无储能（1641 万元）。必须修复后再判断其余指标。

### 建议修复（二选一，推荐 A）

- **方案 A（推荐）——日闭合约束**：在 `daily_lp` 与 `stage_lp` 中强制 E(24)=E(0)（每日储能回到初始 6000），与 Q1 的"0:00 与 24:00 储电量相同"一致；简单、可辩护、消除倒空。
- **方案 B——终态残值**：给储能期末加残值（按次日电价折算），保留跨日连续（与 Q2 一致），但需选定残值价、实现更复杂。

> 方案 A 对每日重复电价/负荷是稳态合理近似，且与 Q1 显式约束一致，建议采用。
