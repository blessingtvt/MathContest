# Q3 决策选择卡（decision-prompt-builder）

> 待人类确认模型选型。确认后由 modeler-decision-logger 写入 `q3_decisions.jsonl`。

## 背景

round1 的滚动 MPC 存在储能末端短视缺陷（`terminal_eq=False` 导致储能每日倒空至 1200、含储能反贵于无储能），已解冻。本次在 G2 重新筛选并修正终端约束。

## 方案取舍

### 主模型：M3 滚动时域 MPC + 分段计费线性化
- 与 round1 同框架，**新增储能终端约束**修复倒空；预计总费降至无储能下界以下、与 Q2 量级一致。
- 关键子选择【决策 1】终端处理：
  - **方案 A（推荐）日闭合 E(144)=E(0)=6000**：与 Q1（0:00=24:00 储电量相同）、Q2（逐日循环）一致，简单可辩护，消除倒空。
  - **方案 B 终态残值（按次日电价折算）**：保留跨日连续、捕获跨日套利；实现更复杂，且与 Q2 日循环口径不一致（Q3 恒定日价下跨日套利收益有限）。

### 基线（与主模型同终端约束、同信息、同计费，保证可比）
- **B3 静态不调整**：仅 0:00 计划并执行 → 量化"调整价值"。
- **R3 规则套利**：峰谷贪心充放 + 缺口购电 → 量化"优化价值"。

### 备用
- **F3 MILP 显式分段**：HD4 若导致目标非凸/需显式分段时启用。
- **F3' 鲁棒/随机规划**：预报误差极端、需概率保证时启用。

## 需确认的三个口径

1. **【决策 1】终端处理**：方案 A（日闭合，推荐）vs 方案 B（终态残值）。
2. **【决策 2 = HD4】计费口径**：同区间比较、差量分别套 50%/1.5 倍（推荐默认）vs 其他口径。
3. **【决策 3 = S8】预报粒度**：整点阶梯映射（推荐）vs 线性插值。

## 优化空间小结（相对 round1）

- **必修**：储能终端约束，消除倒空（这是 round1 结果作废的根因）。
- **可增**：更多预报时刻 / 跨日残值，属结果分析的讨论点，不作为主模型必需。
