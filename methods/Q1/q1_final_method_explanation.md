# Q1 最终方法说明（论文模型章节底稿）

> 子题：单日静态优化　|　方法：线性规划（LP）　|　求解器：scipy.optimize.linprog (HiGHS)

## 1. 问题建模

代表日（附件1）给出分时电价 $p_t$、小区负载 $L_t$、光伏预测功率 $\hat G_t$（$t=1,\dots,T$，$T=144$，$\Delta t = 1/6$ h）。在供电不低于负载、储能满足物理约束、且 0:00 与 24:00 储电量相等的前提下，确定各区间计划购电量 $x_t$、储能充电量 $c_t$、放电量 $q_t$，使全天购电费最小。

## 2. 决策变量与目标函数

决策变量（$t=1,\dots,T$）：

$$x_t \ge 0,\quad c_t \ge 0,\quad q_t \ge 0,\quad E_t \in [E_{\min}, E_{\max}]$$

目标函数（最小化全天购电费）：

$$\min\quad C_1 = \sum_{t=1}^{T} p_t\, x_t$$

## 3. 约束条件

**（a）能量平衡**（区间供电 ≥ 负载，光伏与放电可共同供给）：

$$x_t + \hat G_t\,\Delta t + q_t \;\ge\; L_t\,\Delta t + c_t$$

**（b）储能动态**（单向效率 $\eta_c=\eta_d=0.9$）：

$$E_t = E_{t-1} + \eta_c\, c_t - \frac{q_t}{\eta_d}$$

**（c）功率与容量边界**（附录1）：

$$0 \le c_t \le P_{\max}^{c}\,\Delta t,\qquad 0 \le q_t \le P_{\max}^{d}\,\Delta t,\qquad E_{\min} \le E_t \le E_{\max}$$

**（d）终态闭合**（0:00 与 24:00 储电量相等）：

$$E_0 = E_T = 6000\ \text{kWh}$$

其中 $E_{\min}=1200$、$E_{\max}=10800$ kWh，$P_{\max}^{c}=P_{\max}^{d}=5000$ kW。

## 4. 求解方法

该问题为连续线性规划，变量数 $3T+(T+1)=577$。直接调用 `scipy.optimize.linprog(method="highs")`，求解耗时约 0.014 s。由于成本最小化且 $\eta<1$，同区间"边充边放"恒非最优，最优解自然满足 $c_t\,q_t=0$，无需引入整数互斥约束。

## 6. 结论

储能削峰填谷使代表日购电费较无储能（B1）下降 26.9%，较规则套利（R1）再降约 1.1 万元，验证了线性规划相对启发式规则的优化价值。图 `fig1`/`fig2`/`fig3` 分别给出功率平衡、SOC 约束有效性、电价-购电经济调度证据。

## 7. 假设与适用范围

- 区间电量取区间起点功率 × Δt（A5/HD1）；充放电效率单向 0.9（A6/HD2）。
- 光伏全额本地消纳、忽略自放电与线路损耗（S5/S6）。
- 效率方向敏感性：往返效率（$\sqrt{0.9}$）口径下费用变化 −3.77%，结论稳健（见 robustness_report.json）。
