# Q1 模型合理性分析

> **数据来源**：附件1 代表日（每日 144 个 10 分钟区间，Δt = 1/6 h），线性规划（HiGHS）最优解。
> **符号约定**：x 购电量(kWh)、G 光伏(kW)、L 负载(kW)、c 充电量(kWh)、q 放电量(kWh)、E 储电量(kWh)、Pc/Pq 充放电功率(kW)。
> **能量平衡（每区间，kWh）**：x_t + G_t·Δt + q_t **≥** L_t·Δt + c_t（供给 ≥ 需求；等号成立时无弃光，严格大于时为弃光）

---

## 一、约束条件检验（必须）

### 1.1 功率平衡检验 —— 供给 ≥ 需求（不等式，非等号）

约束为**不等式**「微网供电不可低于小区负载」。对每个 10 分钟区间定义弃光残差：

$$
r_t = (x_t + G_t\,\Delta t + q_t) - (L_t\,\Delta t + c_t) \;\ge\; 0
$$

| 检验项 | 数值 | 结论 |
| --- | --- | --- |
| 最大残差 max\|r_t\|（kWh/区间） | 2.27×10⁻¹³ | 机器精度量级 |
| 折合功率 max\|r_t\|/Δt（kW） | 1.36×10⁻¹² | ≈ 0 |
| \|r_t\| > 10⁻⁶ 的区间数 | 0 / 144 | 无一处失衡 |

**结论**：全部 144 个区间满足「供给 ≥ 需求」（r_t ≥ 0），且 r_t ≈ 0 —— 代表日光伏未超过负载与储能吸纳能力，**无弃光**；r_t 未出现负值，**无供电缺口**。注意：r_t = 0 是 Q1 代表日的**特例**（不等式取等号），并非能量平衡本身是等式；Q2 全年高光伏日会出现 r_t > 0（弃光），属正确行为。

### 1.2 储能容量检验 —— SOC 是否越界

| 检验项 | 数值 | 结论 |
| --- | --- | --- |
| E(t) 取值范围 | [1200, 10800] | 全程成立 |
| 越界区间数（低于 1200 或高于 10800） | 0 | 无越界 |
| 上界 10800 触及时刻 | 5:40–5:50、14:30–18:00 | 午间光伏富余时充满 |
| 下界 1200 触及时刻 | 20:40–21:50 | 晚高峰放电至下限 |
| 首尾闭合 | E(0) = E(24) = 6000 kWh | 终态回到初始 |

**结论**：容量约束 1200 ≤ E(t) ≤ 10800 全程满足；储能既"充满"又"放空"，两端均被充分利用，说明约束是**紧的**，模型没有保留无效容量。

### 1.3 充放电功率检验

| 检验项 | 数值 | 结论 |
| --- | --- | --- |
| 充电功率 max Pc = c/Δt | 5000.00 kW | 恰达额定上限，越限 0 |
| 放电功率 max Pq = q/Δt | 4293.92 kW | 越限 0 |
| 同区间充放同时（c·q > 0）的区间数 | 0 | 满足充放电互斥 |

**结论**：0 ≤ Pc, Pq ≤ 5000 kW 恒成立，且任意时刻充放电互斥，物理合理性满足。

## 二、结果合理性分析（建议）

### 2.1 峰谷套利合理性

按电价分段统计储能充放电能量：

| 电价区间 | 区间数 | 充电量(kWh) | 放电量(kWh) | 行为 |
| --- | --- | --- | --- | --- |
| 低价（p < 0.55） | 58 | 17769.5 | 0.0 | 100% 充电 |
| 平价（0.55 ≤ p ≤ 0.85） | 20 | 1130.0 | 2537.6 | 少量调整 |
| 高价（p > 0.85） | 66 | 1841.1 | 14262.4 | 集中放电 |

- **低价充电占比** = 17769.5 / 20740.7 = **85.67%**
- **高价放电占比** = 14262.4 / 16799.9 = **84.90%**

**关于"高价区间仍充电 1841.1 kWh"的核查**：逐一检查这 15 个高价充电区间，其购电量 x_t = 0，且光伏 G_t·Δt > 负载 L_t·Δt（午间光伏富余），充电完全来自**免费光伏消纳**，而非电网购电。因此这是"消纳光伏富余"，不是"高买低卖"的错误套利。

**结论**：储能呈现清晰的**"谷充峰放"**经济行为，与峰谷电价套利预期一致。

### 2.2 储能循环合理性

储电量 E(t) 每日轨迹：

```
6000(0:00) → 10050(2:00) → 10800(5:40–5:50) → 1974(10:00)
→ 10800(14:30–18:00) → 1200(20:40–21:50) → 6000(24:00)
```

- 夜间低谷充电至接近满 → 早高峰放电 → 午间光伏再充满 → 晚高峰放空至下限 → 夜间回充至初始
- **一日调度后恢复初始状态**：E(0) = E(24) = 6000 kWh

**结论**：储能完成一个完整充放循环后回到初始状态，具备日周期可重复调度能力，满足"次日可继续运行"的闭环要求。

## 三、优化效果验证（推荐）

### 3.1 无储能基准对比

**基准方案**：无储能——每个时段供电缺口全部由外网按实时电价购买，无充放电决策。

| 方案 | 全天购电费用 | 相对基准 |
| --- | --- | --- |
| 无储能基准 Co | 48052.05 元 | — |
| 优化模型 Cn | 35126.95 元 | −12925.10 元 |

$$
\text{成本降低率} = \frac{C_o - C_n}{C_o} = \frac{48052.05 - 35126.95}{48052.05} = 26.90\%
$$

**结论**：引入储能 + 优化调度使单日购电成本下降 **26.90%**，模型具有显著经济价值，优化有效。

---

## 综合结论

Q1 模型通过全部三项约束检验（能量守恒、容量约束、功率约束），结果符合峰谷套利与储能循环的经济直觉，优化相对无储能基准降低 26.90%——**模型合理、有效、物理自洽**。

**两个值得注意的"紧约束"现象**（非问题，而是优化解的自然特征）：

1. **夜间充电功率达上限**：0–2 小时充电功率触及 5000 kW 额定值，说明储能受充电速率限制，若放宽 Pmax 可进一步压低购电成本。
2. **储能两端用满**：既触及 10800 上界、又触及 1200 下界，说明容量与功率约束都被充分利用，模型没有"闲余"；但也意味着晚间无备用裕量（在 Q1 完美预见下可接受，Q3 的实时不确定性中需额外关注）。
